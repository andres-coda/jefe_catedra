# WEB_2-TPE_parte_1
Trabajo practico entregable para Web_2 de la carrera Tudai

### Diagrama de relaciones de entidades ###
El proyecto cuenta con once tablas (area, curso, curso_completo, curso_completo_profe, curso_escuela, 
curso_escuela_dia, dia, escuela, materia, profesor, usuario). 
La tabla usuario va a tener el control de las tablas relacionada con ella, y va a tener permisos para insertar, editar y eliminar datos.
El administrador va a tener privilegios para editar, y eliminar algunso tablas especificas.

Hay relaciones 1--N entre las siguientes tablas

usuario (1 ----- N) curso_completo;
usuario (1 ----- N) profesor;
escuela (1 ----- N) curso_escuela;
curso   (1 ----- N) curso_escuela;
materia (1 ----- N) curso_escuela;
dia     (1 ----- N) curso_escuela_dia;
curso_escuela (1 --- N) curso_escuela_dia;
area    (1 ----- N) materia;

Y relaciones  N--N entre las siguientes tablas

profesor (N ---- N) curso_completo;

El diagrama esta en la imágen png. Fue realizado con la construcción automatica de diagramas de Date Grip 2026.
