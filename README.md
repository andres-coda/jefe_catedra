# jefe_catedra
Repositorio de Andres Coda para las tres parte del trabajo entregable de la materia WEB 2 de la carrera de TUDAI 

### Integrantes del grupo ###
-- Andres Coda - acoda@alumnos.exa.unicen.edu.ar

### Tematica del Tpe ###
La idea del trabajo es crear una app que sirva de anotador para les jefxes de catedra de las diferentes areas en la educación secundaria bonaerense, para
facilitar el seguimiento y la administración de datos de profesorxs, planificación, cursos, materias y horarios.
La app va a tener acceso libre para cualquier persona que entre a la pagina, va a poder ver las escuelas, las areas, los cursos, carga horaria de materias, 
dias y horario que se cursa cada materia. Como un calendario de materias de las escuelas cargadas.

Les usuaries (jefxs de catedra) van hacer crud sobre datos de les profesorxs de cada curso, de cada materia perteneciente a su area,
y si entregaron planificación y trabajos practicos para les alumnes.
